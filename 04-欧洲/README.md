# 卷四 · 欧洲

欧洲占卜传统源远流长，从古希腊德尔菲神谕的庄严仪式、罗马占卜官的鸟占制度，经由凯尔特德鲁伊与北欧卢恩符文的神秘实践，到中世纪阿拉伯占星术的拉丁翻译运动所引发的知识变革，再到文艺复兴时期赫尔墨斯主义的复兴与塔罗牌的转型，直至19世纪以降神秘学运动的兴起与当代新时代运动——欧洲占卜史展现出一条理性与神秘交织、传承与断裂并存的独特演变脉络。

## 本卷结构

- **01-希腊罗马**：古希腊、古罗马
- **02-凯尔特与日耳曼**：德鲁伊传统、卢恩符文、北欧巫术
- **03-斯拉夫**：斯拉夫多神教与基督教化后的占卜存续
- **04-中世纪至近代西方**：中世纪、文艺复兴至启蒙、近现代神秘学复兴
