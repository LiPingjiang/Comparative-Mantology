# 专题：骨占与投骨占卜（Bone Divination / Ditaola / Ukubhula / Scapulimancy）

> 《谶纬流变》深度研究专题 | 作者：李平江
> 研究语言：祖鲁语（isiZulu）/ 塞索托语（Sesotho）术语、英语、中文
> 科学性评级：低（预测效力无实证支持；但作为"信息随机化装置"和诊断性咨询工具具有可论证的认知功能价值）| 实用性评级：中高（南非法律承认的传统医疗体系核心诊断手段，非洲骨占估计服务约80%南非人口；东亚甲骨占卜是人类文字与国家治理制度的直接源头）

---

## 一、历史源流（编年）

### 1.1 南部非洲：Ditaola / Ukubhula 骨占体系

| 时期 | 事件 |
|------|------|
| 史前（狩猎采集时期） | 卡拉哈里桑人（San/Bushmen）恍惚舞蹈（trance dance）岩画证据可追溯至数千年前，是骨占-治疗一体的原型 [Web-BN-009] |
| 班图迁徙（前500—公元1000年） | 班图语族群南下带来铁器、畜牧业与祖先崇拜信仰体系，骨占传统随之在南部非洲扩散 |
| 约700—1500年 | 阿拉伯商人经斯瓦希里海岸带来伊斯兰占星学（'ilm al-nujum）与拉赫曼占卜（ramal），与本土班图占卜传统融合 |
| 约1700—1900年 | 祖鲁王国建立与扩张时期，Sangoma（传统治疗师-占卜师）在军事与政治决策中扮演顾问角色 |
| 约1850—1994年 | 殖民统治与种族隔离时期：传统占卜被殖民政府与基督教传教士系统性压制，多国立法试图取缔骨占（ditaola），Sangoma 被边缘化或刑事化，但据学者记载骨占"仍然非常盛行且是一种高度受尊重的技艺" [Web-BN-001] |
| 1994年至今 | 后种族隔离时代：南非新宪法保护传统文化实践 |
| 2007年 | 南非《传统卫生从业者法》（Traditional Health Practitioners Act）正式承认传统治疗师的法律地位，Sangoma/Inyanga的诊断-占卜职能获得国家法律层面的认可 [Web-BN-002] |
| 2016年（Makgopa研究） | 学者 Makgopa 在林波波省 Sekhukhune 地区对25名传统治疗师进行系统性访谈研究，发表《Ditaola（占卜骨）在原住民治疗师中的使用》，是目前对该体系最系统的民族志/人类学记录 [Web-BN-003] |

**核心操作与工具**：Ditaola（塞索托语，"占卜骨"）或 Amathambo（祖鲁语，"骨头"）通常包括动物骨骼（山羊、绵羊、鬣狗、狒狒等）、贝壳、多米诺骨牌状木块、硬币及其他日常/自然物件，每个物件被赋予特定的象征身份（如代表家族成员、祖先、witch craft等）。Sangoma 或 Inyanga 将骨袋抛掷于地面或兽皮上，根据物件落地后的位置、朝向、彼此距离和排列组合关系进行解读 [Web-BN-004] [Web-BN-005]。

Sangoma 的培养以"祖先召唤"（乌昆瓦莎，ukuthwasa）过程为核心——被认为遭祖先灵选中的人经历一系列身心症状（俗称"thwasa 病"），随后拜入资深 Sangoma 门下经历数月至数年的学徒训练，学习骨占解读、草药知识与仪式规程 [Web-BN-006]。

骨占在传统医疗体系中主要承担**诊断**（而非单纯预言）功能——用以判断疾病的灵性/巫术成因、识别行巫者、预测法庭审判结果等 [Web-BN-007]。

### 1.2 东亚：甲骨占卜（殷商卜骨与龟甲占卜）

| 时期 | 事件 |
|------|------|
| 新石器时代晚期（约5000年前） | 龙山文化遗址已出现经灼烧的兽骨（牛、羊、鹿肩胛骨），表面可见明显灼痕，是甲骨占卜的雏形 [Web-BN-010] |
| 夏代早期 | 内蒙古朱开沟遗址出土卜骨，钻凿形态已趋规范化 |
| 二里头文化三期（约前1800—前1600年） | 出现初步的兆纹识别系统，黄河中游偏好兽骨、长江流域多见龟甲占卜的地域分化已现端倪 [Web-BN-010] |
| 商代晚期（约前1300—前1046年） | 甲骨占卜制度在殷墟（今河南安阳小屯村）达到鼎盛，占卜材料主要为龟腹甲/背甲及牛肩胛骨，占卜前须经锯、刮、凿、钻、磨等"整治"工序 |
| 1899年 | 甲骨文被王懿荣、刘鹗等学者首次系统辨识为古代文字，此前甲骨长期被当作"龙骨"药材售卖 |
| 1899年至今 | 殷墟甲骨文累计出土约15万片，经科学考古发掘者逾3.5万片，单字数量逾4000字 [Web-BN-011] |
| 现代科技考古（2024年河南省文物考古研究院实验复原） | 学者通过实验考古复原商代卜骨制作流程，验证钻凿-灼烧-裂纹的技术工艺 [Web-BN-012] |

**技术流程**：贞人（占卜官）在龟甲/兽骨背面钻凿出圆形或椭圆形凹槽（不打穿正面），用燃烧的木条灼烧凹槽，甲骨受热后正面产生不规则裂纹（"卜"兆，甲骨文"卜"字即取象于裂纹形态），贞人依裂纹走向判定吉凶。占卜完毕后，将占卜的时间、内容、结果及事后应验情况契刻于甲骨之上，形成"卜辞"，这正是甲骨文字的来源 [Web-BN-013] [Web-BN-014]。

甲骨占卜内容涵盖商代天文、地理、军事、农业、交通、宗教等社会生活各方面，最著名案例包括殷墟出土的商王武丁时期"天气预报"卜辞——完整呈现占辞与验辞（事后验证记录）的对应关系 [Web-BN-015]。2017年，中国甲骨文入选联合国教科文组织"世界记忆名录"（Memory of the World Register），认可其作为人类最早成熟文字系统之一及商代历史核心文献的价值 [Web-BN-016]。

### 1.3 北美：Naskapi 肩胛骨占卜（Scapulimancy）

北美东北部亚北极的 Naskapi（今称 Innu）猎人在集体狩猎驯鹿前，将驯鹿肩胛骨在火上灼烧，依据裂纹指示的方向决定次日的狩猎路线——这一实践因人类学家 Omar Khayyam Moore 于1957年发表的经典论文而在学术界获得全新的理论解读（见第二部分）[Paper-BN-001]。

## 二、科学证据

### 2.1 预测效力：无科学证据，但学术界对其"功能"提出了重要的替代性解释

与所有基于随机事件解读的占卜体系一样，**没有任何对照实验证明骨占（无论是非洲Ditaola、殷商甲骨还是Naskapi肩胛骨）具有超出随机概率的预测能力**。Ditaola 的解读高度依赖治疗师个人经验与直觉，缺乏可重复、标准化的解读协议 [Web-BN-003]。

但骨占研究史上出现了一个在整个《谶纬流变》项目中颇具方法论意义的理论突破——**"占卜作为随机化装置"假说**：

**Omar Khayyam Moore（1957）—— 猎人肩胛骨占卜的博弈论解读**
- 论文：*Divination—A New Perspective*，*American Anthropologist*, Vol. 59, No. 1, pp. 69–74（1957）
- DOI: 10.1525/aa.1957.59.1.02a00060
- 核心论点：Moore 观察到 Naskapi 猎人依赖驯鹿肩胛骨灼烧裂纹决定狩猎方向，提出这一"占卜"行为的真实功能并非获取超自然信息，而是**打破人类决策中的系统性偏差（如猎人总倾向去此前成功的地点打猎，导致猎物被过度捕猎而察觉、逃离）**。裂纹的随机性质使得狩猎路线选择在统计学意义上被"随机化"，从而避免猎物因人类狩猎模式的可预测性而产生适应性规避——类似于博弈论中混合策略（mixed strategy）能够防止对手（猎物）预判己方行动的原理 [Paper-BN-001]
- 这一假说的理论价值在于：它首次提出占卜可以在**不具备任何超自然效力**的前提下，仍然对使用者的实际生存产生**客观正面的功能性收益**——即"占卜的有效性"与"占卜的真实性（灵验性）"是两个可以完全脱钩的问题

**后续学术界的批判性回应**：
- 该假说随后受到多位人类学家的方法论质疑。JSTOR 收录的批评论文（"The Shoulder-Blade Path Revisited: A Belated Response to Omar Khayyam Moore"）指出，Moore 的原始论证缺乏对 Naskapi 实际狩猎数据的实证支持，其"随机化提升捕猎成功率"的核心机制未经检验 [Web-BN-017]
- 另一篇质疑文章（*Divination: "Adaptive" from Whose Perspective?*）指出一个关键的经验性反驳：Naskapi 人也猎捕熊、驼鹿、水獭、貂、野兔、海豹、鸟类、松鼠、黄鼠狼、蚂蚁和虫子等多种动物，但**唯独没有将肩胛骨占卜术应用于除驯鹿外的其他猎物**，这一选择性使用模式与"占卜是普遍适用的狩猎随机化装置"这一强假说存在张力 [Web-BN-018]
- 2025年一篇重新审视该假说的论文（*Randomization, Ritual, and Cultural Evolution: Revisiting Omar Khayyam Moore*）在文化演化理论框架下对该假说进行了当代再评估，试图厘清哪些具体条件下"占卜即随机化"的机制可能成立 [Web-BN-019]

**评估结论**：Moore 假说虽未获得决定性实证支持，但它开创了将占卜实践置于"决策理论/博弈论功能分析"框架下研究的传统，为理解为何"不具备超自然效力的占卜"能在人类社会中长期存续提供了重要的替代性解释路径——这一视角同样适用于理解非洲骨占、阿拉伯沙占等结构相似的随机化占卜体系。

### 2.2 甲骨占卜的信息学与制度史价值：无可争议的文明史意义

与预测效力的空白形成鲜明对比的是，殷商甲骨占卜在文字学、考古学与国家制度史层面拥有极高且无争议的学术价值：

- 甲骨文是汉字体系可确证的最早成熟形态，其"卜辞+验辞"的记录格式（占卜内容+事后应验情况对照记录）构成了人类已知最早的系统性"预测-复核"档案实践之一 [Web-BN-015]
- 甲骨占卜制度与商代官僚体系（贞人集团）、王权合法性建构紧密交织，考古学家指出更精细化的占卜程序往往与官僚制度作为国家权力来源相关联（参见美国《The Journal of Anthropological Research》等刊物对中国新石器至周代占卜遗存的多区域比较研究）[Web-BN-020]
- 2017年联合国教科文组织将甲骨文列入《世界记忆名录》，认可其作为文字起源和商代信史核心文献的独特价值 [Web-BN-016]

### 2.3 骨占的诊断/心理咨询功能：人类学的正面评价

- Makgopa（2016）对林波波省25名传统治疗师的系统性访谈研究发现，Ditaola 骨占的分类命名体系反映了"人类与环境之间的密切关系"，骨占的社会功能之一是为求诊者提供**结构化的问题解释框架**，将模糊的疾病/困境归因于可命名、可处理的灵性/社会范畴（如祖先不悦、巫术、违反禁忌等）[Web-BN-003]
- South African History Online 等资料确认，南非多种传统药用植物已从传统医学进入现代药理学验证体系，证明传统治疗师的**草药知识**部分具有客观药理学基础——但这是与"骨占诊断"本身相独立的知识维度 [Web-BN-002]
- 骨占-治疗一体化模式使 Sangoma/Inyanga 在南非农村地区承担了心理疏导、社区仲裁和文化传承的多重功能，据估计南非约有20万名传统治疗师，为约80%人口提供某种形式的医疗/咨询服务 [Web-BN-002]

## 三、批评与争议

### 3.1 科学怀疑论：解读的主观性与缺乏对照实验

- Ditaola 骨占的解读高度依赖治疗师个人经验和直觉，不存在标准化、可验证的解读规则，无法通过双盲对照实验检验其诊断准确性 [Web-BN-003]
- 骨占的"命中"体验可由巴纳姆效应（Barnum effect）、冷读术（cold reading）与确认偏误（confirmation bias）充分解释——这与塔罗牌、Ifá占卜等其他基于随机/半随机符号系统的占卜术面临完全相同的认识论问题

### 3.2 殖民与后殖民语境下的知识体系政治

- 骨占在殖民及种族隔离时期曾被系统性地污名化为"迷信"（superstition）与"巫术"（witchcraft），多国立法试图取缔，这一压制本身是殖民认识论对非西方知识体系的暴力实践的典型案例
- 2007年南非《传统卫生从业者法》的立法承认，代表了后殖民国家在"文化尊重"与"科学问责"之间寻求平衡的尝试——法律承认 Sangoma 的执业地位，但并未（也不应）等同于对其占卜诊断准确性的科学背书
- 与Ifá占卜案例相似，本项目坚持的立场是：**对超自然预测声称的科学评估标准应跨文化一致**，骨占的诊断效力主张应接受与其他占卜体系相同的证据检验，但**其作为社区医疗基础设施和文化知识载体的社会功能评价应语境敏感**

### 3.3 甲骨占卜"科学性"的历史学限定

- 需要明确区分：甲骨占卜作为"预测吉凶的巫术手段"在科学意义上不具备超自然效力（裂纹本质上是骨料材质、钻凿深度、灼烧火候等物理因素共同作用的结果，其"吉凶"判读规则古今学者均未能确证存在稳定内在逻辑）[Web-BN-014]
- 但甲骨占卜作为"信史书写制度"和"文字起源载体"具有确凿无疑的历史学价值——这与 Ifá 占卜案例中"二进制数学结构有学术价值，但预测无效力"的分层评价逻辑完全一致

### 3.4 Moore假说的争议性：警惕"功能主义过度诠释"

- 如2.1节所述，Moore 关于 Naskapi 肩胛骨占卜"随机化提升狩猎效率"的假说本身未获得决定性实证检验，其选择性应用于驯鹿而非其他猎物的经验事实对该假说构成了直接挑战
- 这提示研究者在援引"占卜具有隐藏适应性功能"类解释时应保持审慎——功能主义解释本身也需要经受实证检验，不能因其"听起来合理"就替代缺失的直接证据

## 四、综合评估

| 维度 | 评级 | 依据 |
|------|------|------|
| 科学性（预测能力，非洲Ditaola） | **低** | 无对照实验支持；解读高度主观，依赖治疗师个人经验 |
| 科学性（预测能力，殷商甲骨） | **无** | 裂纹解读规则未见稳定内在逻辑，属前科学时代的巫术实践 |
| 科学性（决策理论/博弈论价值，Naskapi假说） | **理论价值中等，实证薄弱** | Moore(1957)提出的"随机化装置"假说具有重要的方法论启发意义，但未获决定性实证支持，且存在选择性应用的经验反例 |
| 科学性（文字学/制度史价值，甲骨占卜） | **极高** | 汉字最早成熟形态的直接物证；2017年UNESCO《世界记忆名录》；商代信史的核心文献来源 |
| 实用性（南非骨占，当代社区功能） | **高** | 2007年南非法律正式承认；约20万传统治疗师服务约80%人口；诊断-心理咨询-社区仲裁多重功能 |
| 实用性（甲骨占卜，当代） | **无（活态实践已消亡）** | 作为占卜术已不复存在，仅存于考古学/文字学研究领域 |
| 跨文化比较价值 | **高** | 骨占（灼烧骨料裂纹判读）在非洲、东亚、北美三大洲独立发展，是研究"趋同占卜技术"的经典案例 |

**核心结论**：骨占是《谶纬流变》项目中"科学性"与"制度/文化价值"分离最为鲜明的案例之一。作为预测未来或诊断疾病成因的技术手段，无论是非洲的 Ditaola/Ukubhula、殷商的甲骨占卜，还是北美 Naskapi 的肩胛骨占卜，均不具备可验证的超自然效力——这是三个独立发展的骨占传统共享的根本局限。但三者在各自的知识体系脉络中承载着截然不同、且各自意义重大的历史功能：南非骨占是当代仍具法律地位、服务数千万人口的活态社区医疗-咨询基础设施；殷商甲骨占卜是汉字文明和早期国家治理制度的直接物证载体；Naskapi 肩胛骨占卜则催生了 Omar Khayyam Moore 具有开创性但仍存争议的"占卜作为决策随机化装置"理论框架，为理解"无效占卜为何能在演化/社会意义上长期存续"提供了一种重要但尚待验证的解释路径。三者共同印证了本项目的核心方法论原则：技术手段的"科学有效性"评估与其"历史/文化/制度价值"评估应当分层进行，不可混为一谈。
