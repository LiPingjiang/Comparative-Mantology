# 卷五 · 撒哈拉以南非洲

## 卷首导言

撒哈拉以南非洲大陆孕育了世界上最为多样的占卜传统。从西非丛林中 Babalàwo 祭司投掷棕榈果的伊法（Ifá）神谕，到南部非洲草原上 Sangoma 投掷骨片的骨占（ukubhula），非洲占卜不仅是一种预测技术，更是社会治理、医疗实践与宇宙观表达的核心制度。

非洲占卜传统的多样性体现在以下几个维度：

- **技术谱系的广度**：从二进制式的伊法占卜（16×16=256 种 Odù 组合），到骨占的多符号系统，从恍惚状态下的神灵附体到符号解读，技术手段跨越了概率推演、直觉灵媒与象征诠释等多种范式。
- **社会功能的深度绑定**：在殖民前的非洲王国（如贝宁王国、阿散蒂联邦），占卜师往往是王权合法性的赋予者与争端裁决者。占卜结果直接影响战争决策、王位继承、司法判决与农业生产。
- **知识传承的严格性**：伊法体系要求 Babalàwo 经过长达数十年的口传训练，背诵 256 首 Odù 经文，每一首都包含数千行诗歌、神话与药方，构成了世界上最大的口传知识体系之一。
- **跨大西洋的传播与变异**：奴隶贸易将非洲占卜体系带到美洲，在巴西、古巴、海地等地与天主教、本土信仰融合，催生了 Candomblé、Santería、Vodou 等至今活跃的宗教传统。

本卷按地理区域分为三章：西非（伊法体系与 Fon、阿散蒂传统）、东非与南非（祖鲁骨占、桑人恍惚占卜、斯瓦希里海岸的阿拉伯影响），以及非洲占卜的跨大西洋传播（美洲变体与存续）。
