# 西非 · 伊法与符号帝国（前1000年—当代）

## 研究对象

- **约鲁巴 Ifá 占卜体系**：以 16 颗棕榈果（或占卜链）产生 16 种基本 Odù，两两组合为 256 种 Odù 组合。每一 Odù 对应大量口传经文（ese Ifá），涵盖神话、历史、药方与道德训诫。Babalàwo（"父亲之秘密"）为伊法祭司，经数十年训练掌握 Odù 经文的诵读与诠释。
- **Fon 族 Fa 占卜**：贝宁（旧称达荷美）地区 Fon 族的占卜体系，与约鲁巴 Ifá 同源但发展出独立变体。Fa 占卜同样使用 256 个"Du"（对应 Odù），由 Bokono 祭司执掌，在达荷美王国时期与王权治理深度结合。
- **阿散蒂 Adinkra 符号象征体系**：加纳阿散蒂族的视觉符号系统，包含数十种象形符号，每种符号承载特定的哲学格言与占卜寓意。Adinkra 符号广泛应用于织物、建筑与仪式器物，是占卜结果的可视化表达媒介。

## 编年范围

| 时期 | 主要节点 |
|------|----------|
| 史前与早期铁器时代（前1000—前500年） | 考古证据显示西非地区已有占卜实践的物质遗存（占卜工具、仪式遗址） |
| 诺克文化时期（前500—公元200年） | 诺克文明的 terracotta 雕像暗示早期祭司-占卜师角色 |
| 约鲁巴城邦兴起（约800—1200年） | 伊费（Ife）成为约鲁巴文明中心，Ifá 体系口传经文逐步系统化 |
| 贝宁王国鼎盛期（约1300—1600年） | 占卜师成为王室核心顾问，参与王位继承与战争决策 |
| 大西洋奴隶贸易期（1500—1800年） | 西非占卜师被掠卖至美洲，Ifá 体系在殖民地开始变异 |
- 殖民前王国时期（约800—1900年） | 阿散蒂联邦、达荷美王国等政体中占卜制度化嵌入治理体系 |
- 殖民统治与基督教/伊斯兰冲击（约1900—1960年） | 占卜实践遭受压制但转入地下，部分体系与殖民宗教融合 |
- 后殖民时代的复兴与全球化（1960年—当代） | Ifá 被联合国教科文组织列入非遗（2005年），Babalàwo 在尼日利亚及散居社群中活跃传承 |
