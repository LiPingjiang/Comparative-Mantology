# 谶纬流变

**Comparative Mantology — 比较卜筮学**

对全球巫术、预测与社会控制的历史研究。

本项目以地域为经、编年为纬，系统梳理古今中外的占卜、谶纬、巫术及预测技术，考察其起源、演变、跨文化传播与社会控制功能，最终提炼出在可信度与实用效果上经得起检验的那部分技术遗产。

## 研究范围

涵盖以下主要文明区域的卜筮传统：

东亚（中国、日本、朝鲜半岛、越南）、南亚与东南亚（印度、西藏、东南亚诸国）、西亚与北非（美索不达米亚、埃及、波斯、阿拉伯）、欧洲（希腊罗马、凯尔特、日耳曼、斯拉夫及中世纪至近代西方）、撒哈拉以南非洲、美洲原住民，以及近现代的跨文化融合与科学化转型。

## 研究方法

按地域分卷、按时代编年，在各文明内部纵向追踪技术流变，同时横向比较不同文化中功能相近的预测体系。综述文章汇总各门类的可信度评估与实用效果分析，力求在历史考据与理性审视之间取得平衡。

研究严格遵循**原语言检索**原则——各文明的卜筮传统使用对应国家的原语言进行资料检索，不依赖单一语种的二手转述。所有事实性信息均保留**出处索引**（网站、书籍或论文），做到可追溯、可验证。详见 [METHODOLOGY.md](METHODOLOGY.md)。
