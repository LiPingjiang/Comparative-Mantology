# 卷六 · 美洲原住民

## 卷首导言

美洲原住民的占卜传统与历法体系、宇宙观及生态知识紧密交织，构成了一种独特的"时间-命运"认知框架。与旧大陆的占卜传统不同，美洲原住民占卜往往不以个人命运的预测为核心，而更强调群体周期、宇宙节律与人与自然关系的校准。

美洲占卜传统的核心特征包括：

- **历法即占卜**：中美洲的 Tzolk'in（260 天神圣历）与 Tonalpohualli（260 天命运历）本身就是占卜工具——每一天由特定的日符与数字组合标记，直接决定新生儿的命运、仪式的时机与行动的吉凶。历法不是被占卜的对象，而是占卜的媒介本身。
- **致幻植物与神谕**：从玛雅的蘑菇崇拜（Psilocybe）到亚马逊的死藤水（ayahuasca），致幻植物在美洲占卜中扮演核心角色。萨满通过 altered states of consciousness 进入灵界，获取疾病诊断、敌情情报与社区决策所需的信息。
- **生态嵌入性**：北美原住民的视觉寻求（Vision Quest）与汗屋仪式（Sweat Lodge）将占卜实践嵌入到与特定地理环境（山丘、河流、荒野）的互动中；安第斯的古柯叶占卜则直接依赖高原生态系统。
- **殖民断裂与当代复兴**：西班牙殖民者系统性地摧毁了中美洲的占卜文献（Codex）与祭司阶层，但部分传统在地下存续，并在 20 世纪末以来经历了文化复兴运动。

本卷按地理区域分为三章：中美洲（玛雅与阿兹特克）、南美洲（安第斯与亚马逊）、北美洲（概述）。
