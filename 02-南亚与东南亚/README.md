# 卷二：南亚与东南亚占卜传统

本卷覆盖印度、西藏及东南亚诸国的占卜与占星传统，以吠陀占星术（Jyotish）为核心向外辐射，考察其在不同历史时期、不同文化语境中的演变、传播与本土化。

## 卷次结构

- **印度**：从吠陀时期的占卜萌芽，经古典时期的体系化发展，到伊斯兰与殖民时期的跨文化融合，再到近现代的制度化复兴。
- **西藏**：从苯教自然征兆与骰子占卜，到藏传佛教时期与时轮历法深度融合的占星卜问体系。
- **东南亚诸国**：印度占星体系的本土化、华人占卜传统的南传、伊斯兰占卜的传播，以及万物有灵论底层的预兆解读。

## 研究主线

1. Jyotish 作为南亚占卜知识的核心体系，其内部分化（Nadi、Prasna、Samudrika 等）与向外辐射路径。
2. 宗教更替（吠陀宗教 → 佛教 → 伊斯兰教 → 殖民基督教）对占卜传统的挤压、融合与重塑。
3. 口传秘传与文本经典之间的张力：Nadi 体系的师承密传 vs. Brihat Samhita 的公开编纂。
4. 占卜术与政治权力的关系：莫卧儿宫廷占术、印度独立后的占星政治化。
5. 区域传播中的本土化机制：西藏对印度占星的佛教化改造，东南亚对印度体系的在地调适。
